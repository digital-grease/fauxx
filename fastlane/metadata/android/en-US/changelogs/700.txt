• New: Fauxx now respects metered Wi-Fi. A phone hotspot, or any network you marked metered in Android's Wi-Fi settings, follows your Mobile data intensity setting instead of your Wi-Fi one, so it no longer quietly spends a data allowance. The dashboard says why it paused and offers a one-tap opt-in (#288).
• New: choose which search engines receive synthetic queries. Turn off any engine you would rather spare; at least two stay active so the traffic keeps a realistic spread (#281).
• New: set the battery pause level separately for on-battery and while-charging, instead of one threshold plus an ignore-while-charging toggle. Your existing setting carries over. Contributed by Maingron (#216).
• Improved: recency search queries ("best smartphones 2025") now track the real current year instead of the year they were written, so they no longer read as dated (#256).
• Fixed: tapping Start on the resume notification outside your active hours looked like it did nothing. It now tells you when protection will actually resume (#198).
• Changed: Location Spoofing is now documented as experimental and is no longer listed as a headline feature. Testing on Android 14 showed it registers its own location provider instead of replacing the system one, so apps that request location the usual way are unaffected by it. It stays off by default; see the README for the measured detail.
• Removed two location permissions the app declared but never actually used.
